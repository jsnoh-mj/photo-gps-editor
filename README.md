# Photo GPS Editor & File renamer

사진/동영상의 GPS 위치와 파일명을 로컬에서 바로 확인·수정하는 단일 HTML 도구입니다.
서버나 설치 없이 `photo-gps-editor.html` 파일을 **Chrome 또는 Edge**로 열기만 하면 동작합니다.

> Chrome / Edge 전용입니다. File System Access API를 사용하므로 Firefox, Safari에서는 동작하지 않습니다.

## 주요 기능

- **폴더 단위로 사진/동영상 목록 조회**: JPG, JPEG, PNG, MP4, MOV 인식 (PNG은 GPS 미지원, 파일명 기능만 지원)
- **GPS 위치 조회/수정**
  - 좌표 직접 입력, 구글맵 우클릭 좌표(`위도, 경도`) 붙여넣기, 구글맵 공유 URL 붙여넣기 모두 인식
  - 파일 단위 적용, 체크박스로 선택한 파일만 일괄 적용, 전체 파일 일괄 적용
  - JPEG는 EXIF GPS 태그로, MP4/MOV는 iPhone 등이 쓰는 방식과 동일한 위치 메타데이터(`moov/udta/©xyz`)로 기록 (구글포토, exiftool 등에서 인식)
- **지도에서 위치 확인/수정**: OpenStreetMap 지도에 GPS 있는 파일을 점으로 표시, 드래그로 위치 보정, 같은 좌표 사진은 하나로 묶어서 전체/개별 이동 가능
- **썸네일 1x/4x 보기 전환**: 4x 모드에서 사진/영상 클릭 시 최대 720px 미리보기(영상은 소리 포함 재생)
- **파일명 자동 정리 (4x 모드 전용)**: `YYYYMMDD_HHMMSS_설명부.ext` 형식으로 폴더 전체 일괄 보정, 또는 파일명/설명을 더블클릭해 개별 수정
- **최근 폴더 자동 기억**: 다음 실행 시 이전 폴더를 자동으로 다시 엽니다 (최초 1회는 직접 선택 필요)
- 다양한 기기에서 생성된 file을 YYYYMMDD_HHMMSS 형태의 file로 일괄 변경 및 사진/영상을 미리보기 하면서 file명에 comment추가 기능.

## 사용법

1. `photo-gps-editor.html` 파일을 Chrome 또는 Edge로 엽니다 (더블클릭 또는 브라우저에 드래그).
2. **폴더 선택** 버튼을 눌러 사진/동영상이 있는 폴더를 고릅니다. 쓰기 권한 요청 창이 뜨면 허용합니다.
3. 목록에서 각 파일의 GPS 위치를 확인하고, 필요하면 좌표를 입력한 뒤 **적용**을 누릅니다.
4. 위치가 크게 벗어난 사진이 많다면 **GPS 있는 파일 전체 지도에서 보기**로 한눈에 확인하고 드래그로 고칩니다.
5. 파일명을 정리하고 싶다면 **썸네일 4x 크기로 보기**를 켠 뒤 **파일명 일괄 보정**을 사용합니다.

## 주의사항

- GPS/파일명 변경은 원본 파일을 직접 덮어씁니다. 중요한 원본은 미리 백업해두세요.
- MP4/MOV 쓰기는 파일 내부 구조(박스)를 직접 재구성하는 방식이라, 스트리밍용으로 조각화(fragmented)된 MP4는 지원하지 않습니다.
- 파일명 변경(`move`)은 최신 Chrome/Edge에서만 지원됩니다.
- 지도 기능은 OpenStreetMap 타일을 불러오므로 인터넷 연결이 필요합니다. 그 외 기능은 오프라인에서도 동작합니다.
